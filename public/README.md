# Public Folder

Place your static assets here:

- **resume.pdf** - Your resume PDF file
- **favicon.ico** - Your website favicon
- **images/** - Any images you want to use

These files will be available at the root URL:
- `/resume.pdf`
- `/favicon.ico`
- `/images/photo.jpg`

## Important Notes

1. Make sure your resume PDF is named `resume.pdf` or update the path in `data/portfolioData.ts`
2. Next.js automatically optimizes images in the `public` folder
3. Files in `public` are served as-is without processing
